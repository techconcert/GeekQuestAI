What is new in GeekQuestAI r3:

- The server hall is no longer built a whole row at a time. At most three empty rack frames wait in the hall: when the last empty frame is taken, 1 to 3 new ones appear (random), up to 30.
- New button "Reset game progress" on the clock's status page (next to "Reset game settings"). It asks for confirmation, starts the game over from day 1 with the small starting state and saves the fresh game to the flash within a second. WiFi, weather, sleep and all other settings are untouched.
- The reset uses the existing save area only (no new flash locations); the update and recovery pages are unchanged.
- A game saved by r2 carries over; its rack frames shrink to the new 1 to 3 rule.
- Browser preview: shows how many empty rack frames are waiting.
